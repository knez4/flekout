# FLEKOUT identity exports

## Completed transparent package

Use `logos/png-v1/` or `flekout-transparent-logos-v1.zip`.
18 PNG RGBA exports: black #171717, white #FFFFFF, blue #168CCD.
Wordmark widths: 2048 and 1024 pixels. Symbol sizes: 1024, 512, 128 and 32 pixels.
The F symbol is extracted from the same wordmark. All color variants share pixel-identical alpha masks. Background, diagonal cut and letter counters are transparent. See `logos-preview.png` for a preview on white and charcoal backgrounds.
Generated drafts were cleaned deterministically with user approval, without further AI generation. Original files below are retained for history; use png-v1 instead. These remain raster assets, not vector originals or a guarantee of trademark uniqueness.

- logos/: black, white and blue F symbols. PNG RGBA; verified alpha range 0–255; 1254×1254.
- drafts/: full FLEKOUT wordmarks. NOT transparent: image generator produced baked-in checkerboard twice. These are drafts, not ready exports.
- identity-concept-01.png: approved identity presentation including shirt and van mockups.
- logo-prompts.md: prompts used with built-in imagegen.

All are raster concept assets, not production vector masters. The black wordmark now has real RGBA transparency and is in logos/. White export still fails visual QA; blue alpha export has edge artifacts and is retained in drafts/. The full package is not finished. Further AI regeneration was stopped to avoid wasting usage.
